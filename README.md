# TopDownSurvival
## A Unity project made in the course APR400 at University West (Högskolan Väst)

The project is made by us, two students taking the advanced C# course APR400 at University West (Högskolan Väst), with the Unity game engine. 

Through the project some advanced C# concepts and design patterns have been applied, giving us more knowledge and skill for the future. 

We have used the Unity Editor (version 6000.6.5f1) and Visual Studio Code to work on this game project. 

The platform the game is made for is WebGL to make it possible to run in the browser. 

### Get started guide
You can download this repo and open it in the Unity Editor. Once the editor has launched, you can click the play-button in the middle of the editor's UI to run the game locally. 

Alternatively, you can build the project to upload it on a web hosting service. To do this go through the Unity Editor menus:
> File > Build Profiles > (Add Build Profile for Web, if none exists) > Build (opens file explorer, choose where to save build)

Then you can upload the build as a zip to a web service such as **itch.io** to try the game in your browser.
